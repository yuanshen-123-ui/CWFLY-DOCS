# 命令列表

| 命令 | 说明 | 示例 |
|------|------|------|
| `/fp <航班号>` | 查询飞行计划 | `/fp CCA1234` |
| `/metar <ICAO>` | 查询 METAR 报文 | `/metar ZBAA` |
| `/taf <ICAO1,ICAO2>` | 查询 TAF 预报 | `/taf ZSSS` |
| `/在线状态` | 查看 FSD 连接概况 | `/在线状态` |
| `/机组查询 [呼号]` | 查询在线机组 | `/机组查询` |
| `/管制查询 [呼号]` | 查询在线管制 | `/管制查询` |
| `/机场查询 <ICAO>` | 查询机场信息 | `/机场查询 ZBAA` |
| `/航路 <DEP> <ARR>` | 查询航路 | `/航路 ZSSS ZGHA` |
| `/event` | 查看近期活动 | `/event` |
| `/呼叫管制` | 呼叫在线管制员 | `/呼叫管制` |
| `/ai <内容>` | AI 飞行问答 | `/ai RVSM是什么` |
| `/下载列表` | 查看可下载文件 | `/下载列表` |
| `/下载 <编号>` | 下载文件 | `/下载 1` |
| `/帮助` | 帮助信息 | `/帮助` |
| `/调皮一下 <内容>` | 闲聊模式 | `/调皮一下 你好` |

## 使用限制

- 仅限白名单群组使用。
- 部分命令有调用频率限制（默认 5 秒/次）。

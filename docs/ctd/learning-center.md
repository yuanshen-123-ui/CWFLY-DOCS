# 学习中心

> 本文档部分内容整理自公开资料，包括 **ICAO Annex 2**（空中规则）、**ICAO Annex 11**（空中交通服务）、**ICAO Doc 4444**（空中交通管理）等国际民航组织标准文件。
> 除特别注明外，本文档采用 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/deed.zh) 许可协议。

## 一、简介

学习中心（Learning Center）是 CWFLY 管制员培训中心的核心知识库，汇集了从基础理论到高级管制技能的各类学习资源。无论是刚刚起步的 OBS 观察员，还是正在备考晋升的管制员，都能在这里找到所需的学习材料。

> 注：本文档仅供模拟飞行学习使用，部分内容整理自公开资料，如涉及侵权请联系删除。

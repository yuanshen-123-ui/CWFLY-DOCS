# 空域分类

## 一、概述

空域分类是管制员必须掌握的基础知识。ICAO 将空域分为 A 至 G 七类，各类型空域有不同的运行规则和服务要求。

详细空域分类表格请参阅 [PTD 空域分类](/ptd/airspace)。

## 二、管制员需要掌握的要点

1. **A 类空域** — 仅允许 IFR 飞行，管制员提供全面间隔服务。
2. **B 类空域** — IFR 和 VFR 均可运行，管制员提供全面间隔服务。
3. **C 类空域** — IFR 和 VFR 均可运行，管制员对 IFR–IFR 和 IFR–VFR 提供间隔。
4. **D 类空域** — IFR 和 VFR 均可运行，管制员仅对 IFR 之间提供间隔。

## 三、特殊空域

| 类型 | 说明 | 管制员职责 |
|------|------|-----------|
| 危险区（Danger Area） | 存在对飞行有潜在危险的活动 | 向飞行员通报，建议绕飞 |
| 禁区（Prohibited Area） | 禁止飞行 | 确保航空器不进入 |
| 限制区（Restricted Area） | 特定条件下限制飞行 | 协调穿越或绕飞 |
| 训练空域（Training Area） | 用于飞行员训练 | 与训练空域保持协调 |

## 四、中国空域结构特点

中国空域分为高空管制区（A 类）、中低空管制区（B 类）、进近管制区（C 类）和机场管制区（D 类）。管制员应熟悉所在 FIR 的空域结构图和扇区划分，确保在管制过程中准确掌握空域边界和运行规则。

# 报文解读

## 一、概述

METAR 报文解读是管制员培训和考核的重要内容。管制员应能够快速、准确地解读 METAR 报文，并向飞行员通报气象信息。

详细报文解读方法请参阅 [PTD METAR 报文解读](/ptd/metar-guide)，本部分专注于管制员应用中需要额外掌握的要点。

## 二、管制员需要关注的报文要素

| 要素 | 管制员应用 |
|------|-----------|
| 风向风速 | 确定跑道运行方向，通知飞行员 |
| 能见度 | 判断是否需要降低起降标准 |
| 天气现象 | 评估对飞行的影响，发布 SIGMET 或特殊通报 |
| 云层/云底高 | 判断进近方式，影响 VFR 运行 |
| 修正海压（QNH） | 向飞行员通报，确保高度表校准一致 |
| 趋势预报 | 预判天气变化，提前准备 |

## 三、管制常用气象术语

| 中文 | 英文 | 说明 |
|------|------|------|
| 修正海压 | QNH | 高度表拨正值，用于机场区域飞行 |
| 标准气压 | QNE / 1013 | 标准海压，用于过渡高度层以上 |
| 场面气压 | QFE | 机场场面气压，某些地区使用 |
| 风向风速 | Wind Direction/Speed | 通报跑道方向和风速 |
| 能见度 | Visibility | 跑道视程或主导能见度 |

## 四、练习建议

1. 定期访问 [aviationweather.gov](https://aviationweather.gov/data/metar/) 获取实时报文。
2. 建议优先练习中国大陆带有后续预测（BECMG）的 METAR 报文。
3. 尝试将报文内容转换为可供飞行员直接使用的通报信息。

## 五、报文解读示例

```
METAR ZSSS 081400Z 29005MPS 260V320 9999 BKN016 18/15 Q1019 BECMG TL1540 BKN013
```

管制通报示例：
> "上海虹桥机场天气：风向 290°，风速 5 米/秒，能见度 10 公里以上，多云云底高 1600 英尺，温度 18°C，露点 15°C，修正海压 1019，预计到 15:40 变多云云底高 1300 英尺。"

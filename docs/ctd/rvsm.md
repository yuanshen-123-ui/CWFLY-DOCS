# 飞行高度层

## 一、RVSM 基本概念

RVSM（Reduced Vertical Separation Minimum，缩小垂直间隔标准）将 FL290 至 FL410 之间的垂直间隔从 2,000 英尺缩小至 1,000 英尺，大幅增加了空域容量。详细概念请参阅 [PTD RVSM 飞行高度层](/ptd/rvsm)。

## 二、管制员需要掌握的要点

### 高度层分配

| 航向 | IFR 高度层（FL290–FL410） |
|------|-------------------------|
| 000°–179°（向东） | FL290, FL310, FL330, FL350, FL370, FL390, FL410 |
| 180°–359°（向西） | FL300, FL320, FL340, FL360, FL380, FL400 |

### 管制注意事项

1. 确保进入 RVSM 空域的航空器具备 RVSM 适航能力。
2. RVSM 空域内高度偏离超过 200 ft 时，飞行员应主动报告。
3. 如遇 Turbulence（颠簸），需协调非 RVSM 高度层。
4. 跨 FIR 移交时，须确认移交高度符合接收方的高度层配备规则。

## 三、转换高度

- **TA（Transition Altitude）** — 起飞后从 QNH 转换为 1013 hPa 的高度。
- **TL（Transition Level）** — 进近时从 1013 hPa 转换回 QNH 的高度层。
- **TH（Transition Height）** — 以机场标高为基准的过渡高。

管制员在发布进近指令时，应明确告知飞行员转换高度/高度层。

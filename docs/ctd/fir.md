# 飞行情报区

## 一、概述

飞行情报区（Flight Information Region，FIR）是空中交通管理的基本空域单元。管制员需熟悉所管辖区域的 FIR 边界、相邻 FIR 及协调移交程序。

详细 FIR 列表请参阅 [PTD 飞行情报区 FIR](/ptd/fir)。

## 二、管制员需要掌握的要点

1. **中国 9 个 FIR 的名称和范围** — 确保在跨区飞行时正确协调移交。
2. **周边 FIR 的对接程序** — 了解相邻国家/地区 FIR 的协调方式。
3. **FIR 边界附近的管制移交** — 提前协调移交高度、航向和时间。
4. **各 FIR 的频率和呼号** — 掌握常用管制单位和频率。
5. **不同 FIR 的高度层配备差异** — 注意 RVSM 空域内高度层的一致性。

## 三、跨区移交

跨 FIR 移交是区域管制的重要环节：

1. 在航空器到达 FIR 边界前，当前管制员应与接收 FIR 协调。
2. 确认接收方准备好接受航空器。
3. 将航空器引导至移交点，告知下一频率。
4. 完成移交后记录移交时间和高度。

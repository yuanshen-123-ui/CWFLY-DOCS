# 航图识读

## 一、航图基础

航图是飞行和管制的重要工具，管制员应熟练掌握各类航图的识读方法。本部分与 [PTD eAIP 航图识读](/ptd/eaip-charts) 内容相通，并补充管制员特有的航图应用知识。

## 二、管制员关注的航图要素

### 机场平面图

- 跑道方向、长度、宽度
- 滑行道系统与标识
- 停机位布局
- 等待点（HP）位置

### 标准仪表离场图（SID）

- 离场航线和航路点
- 离场高度限制
- 离场频率

### 标准仪表进场图（STAR）

- 进场航线和航路点
- 高度限制与速度限制
- 等待程序

### 仪表进近图（IAP）

- 进近程序和剖面图
- 最低标准
- 复飞程序

## 三、关键知识点

1. **升降带** — 机场升降带的范围和标识。
2. **频率** — 各管制席位的无线电频率（应掌握所管席位频率）。
3. **航图单位** — 航图中使用的距离（海里）、高度（英尺/米）等单位。
4. **航图编号与发行日期** — 确认航图版本和有效性。
5. **与上期航图相比的更改部分** — 关注航图的变更内容。
6. **特殊的图例**（HS、HP 等）。

## 四、导航方式

- **VOR** — 飞跃（Fly Over）方式导航。
- **RNAV** — 飞跃（Fly Over）或旁切（Fly By）方式导航。

## 五、高度与决断

- TA（过渡高度）、TL（过渡高度层）、TH（过渡高）
- DA（决断高度）、DH（决断高）的区别
- MVA（最低雷达引导高度）、MSA（最低安全高度）

## 六、进近航段

1. 进场段（Arrival）
2. 起始进近段（Initial Approach）— IAF/IF
3. 中间进近段（Intermediate Approach）
4. 最后进近段（Final Approach）— FAF
5. 复飞段（Missed Approach）

## 七、注意事项

- 航图中部分内容**不按比例绘制**。
- 管制员在指挥进近时需结合航图剖面图理解垂直剖面。
- 定期查阅最新航图，关注变更内容。

# 管制员培训中心

文件编号：OPDOC-CTD-202501
发行日期：2026 年 7 月

## 概述

管制员培训中心（Controller Training Department，CTD）是 CWFLY 平台负责空中交通管制员培训、考核和晋升管理的专门机构。我们致力于为有志于从事模拟飞行管制的用户提供系统化、标准化的培训体系。

## 培训体系

```
OBS (观察员) → S1 (地面/放行) → S2 (塔台) → S3 (终端/进近)
    → C1 (区域) → C3 (主任) → I1 (塔台教员) → I2 (进近教员) → I3 (区域教员) → SUP (督导)
```

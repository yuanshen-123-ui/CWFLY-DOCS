> 基本通话用语参考 **ICAO Doc 4444**（空中交通管理）及 **中国民航陆空通话标准**。
> 除特别注明外，本文档采用 <a href="https://creativecommons.org/licenses/by-nc/4.0/deed.zh">CC BY-NC 4.0</a> 许可协议。

## 一、基本要求

标准陆空通话是飞行安全和效率的重要保障。管制员应熟练掌握中英文标准通话用语，确保指令清晰、简洁、准确。

## 七、通话规范注意事项

1. 首次联系时须说明：对方呼号 + 自己呼号 + 信息内容。
2. 管制指令应包含：呼号 + 指令内容 + 复诵要求。
3. 飞行员须完整复诵关键指令（高度、航向、频率、跑道号）。
4. 避免使用俚语、方言和非标准表达。
5. 通话保持简洁，避免不必要的聊天内容。

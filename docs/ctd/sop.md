# SOP

## 第一部分：管制面试

### 面试氛围

面试过程应在轻松、舒适的环境下进行，不应为申请者施加过多心理压力。面试官需始终保持专业、友好的态度，以引导申请者充分展示其能力。

### 宣读纪律

面试开始前，面试官须向申请者宣读以下纪律：

1. 面试过程中请保持诚实，如实回答每一个问题。
2. 如遇到不了解的问题，请如实告知，不要胡乱作答。
3. 面试过程中请保持耐心，完整回答每个环节的问题。
4. 面试过程中不允许使用任何辅助工具或参考资料。

### 环节 1：自我介绍（3–5 分钟）

申请者进行简短的自我介绍，内容包括：
- 基本信息（年龄、所在地区等）
- 模拟飞行与管制相关经验
- 申请管制员的动机与目标

### 环节 2：探讨环节（5–10 分钟）

面试官与申请者进行开放式讨论，了解：
- 对管制工作的理解和认识
- 对平台的了解程度与活跃度
- 可用于管制培训的时间投入
- 团队协作意识与沟通能力

### 环节 3：理论知识考察（15–20 分钟）

**陆空通话能力**
- 中英文基本陆空通话用语掌握情况
- 高度、航向、频率等数字的标准读法
- 通话用语的规范性和流畅度

**管制规章制度**
- 对管制员基本职责的认知
- 对平台行为准则和规则的了解
- 管制员职业道德规范

**METAR 报文解读**
建议使用中国大陆带有后续预测（BECMG）的 METAR 报文进行考察。可访问 [aviationweather.gov](https://aviationweather.gov/data/metar/) 获取实时报文。

```
METAR ZSSS 081400Z 29005MPS 260V320 9999 BKN016 18/15 Q1019 BECMG TL1540 BKN013
```

**eAIP 航图识读**
主要考察知识点：
- 升降带、频率、航图单位
- 航图编号与发行日期，与上期航图的更改部分
- 盲降频率与航道
- 特殊图例（HS、HP 等）
- VOR：飞跃；RNAV：飞跃或旁切
- TA（过渡高度）、TL（过渡高度层）、TH（过渡高）的区别
- DA（决断高度）与 DH（决断高）的区别
- IF、IAF、FAF 等进近定位点的识别
- 五大航段：进场、起始进近、中间进近、最后进近、复飞
- 进场点与离场点
- MVA（最低雷达引导高度）、MSA（最低安全高度）
- 不按比例绘制的要素
- 复飞航段的描述

**RVSM 飞行高度层**
- 8900–12500 m 为 RVSM 空域
- RVSM 空域运行规则与高度层分配原则

**飞行情报区空域运行规范**
- 中国大陆境内飞行情报区数量及名称
- 危险区、禁区的识别与避让

### 环节 4：教员讨论（5 分钟）

面试结束后面试官进行内部评议：
- 综合评估申请者各环节表现
- 讨论申请者的优势与待改进之处
- 确定面试结果

### 环节 5：宣布结果（2 分钟）

- 当场向申请者公布面试结果
- 通过者说明后续培训安排
- 未通过者给予具体改进建议和再次申请时间

## 第二部分：在线管理员 SOP

### 日常巡查

1. 检查在线用户数量及分布情况。
2. 监控管制席位占用状态。
3. 检查 FSD 服务器运行状态与性能指标。
4. 及时处理用户举报和投诉。

### 违规处理

1. 收集违规证据（截图、日志记录等）。
2. 评估违规严重程度，参照处罚标准作出决定。
3. 按照规定执行处罚并记录至审计日志。
4. 通知相关用户处理结果。

### 紧急响应

1. 服务器故障时，及时通知维护人员介入处理。
2. 协助用户解决连接异常等技术问题。
3. 按照标准程序处理特情事件。
4. 重大事件须及时向管理团队汇报。

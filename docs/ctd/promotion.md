# 晋升体系

## 晋升条件

| 当前等级 | 目标等级 | 晋升要求 |
|---------|---------|---------|
| OBS | S1 | 完成基础培训课程，通过理论考试（≥ 70 分） |
| S1 | S2 | 累计管制时间 ≥ 20 小时，通过等级考核 |
| S2 | S3 | 累计管制时间 ≥ 50 小时，通过等级考核 |
| S3 | C1 | 累计管制时间 ≥ 100 小时，通过等级考核 |
| C1 | C3 | 累计管制时间 ≥ 200 小时，通过等级考核 |
| C3 | I1 | 完成教员培训课程，通过教员考核 |

## 晋升流程

1. 满足晋升条件后，通过平台提交晋升申请。
2. 培训中心审核申请者资格。
3. 安排对应等级的理论考试和/或实操考核。
4. 考核通过后，系统自动更新 FSD 等级。

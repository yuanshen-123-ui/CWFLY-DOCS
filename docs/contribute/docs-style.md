# 文档编写规范

## 语言风格

- 使用简体中文撰写，保持语言简练、准确、专业。
- 专业术语首次出现时标注英文原文，如：空中交通管制（ATC）。
- 避免口语化表达，保持正式文档风格。

## 格式要求

- 标题层级不超过三级（`#` → `##` → `###`）。
- 代码示例使用围栏代码块（` ``` `）并标注语言类型。
- 表格对齐清晰，表头使用分隔线标识。
- 使用有序或无序列表组织相关内容，保持结构清晰。

## 文件命名

- 文件名使用小写字母和连字符（`-`）组合。
- 示例：`flight-plan.md`、`code-of-conduct.md`。
- 目录索引文件统一命名为 `index.md`。

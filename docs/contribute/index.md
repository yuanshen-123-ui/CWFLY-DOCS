# 贡献指南

## 如何贡献

我们欢迎所有形式的贡献，共同推动 CWFLY 平台的发展。您可以通过以下方式参与：

- 提交 Bug 报告或功能建议
- 改进和完善文档内容
- 提交代码修复或新功能
- 参与社区讨论和反馈

## 贡献流程

1. **Fork** 本仓库至您的 GitHub 账号。
2. **创建功能分支**：`git checkout -b feature/your-feature`。
3. **提交改动**：编写代码或文档，提交有意义的 commit。
4. **发起 Pull Request**：描述您所做的改动和目的。
5. **等待审核**：项目维护者将审核您的 PR 并提供反馈。

## 报告问题

在 GitHub Issues 中提交问题时，请包含以下信息：

- 清晰的问题描述
- 重现步骤（如适用）
- 预期行为与实际行为
- 截图或日志（如适用）
- 运行环境信息（操作系统、浏览器版本等）

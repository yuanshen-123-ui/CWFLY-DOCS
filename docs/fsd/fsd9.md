# 直连协议

## 概述

FSD9 是 FSD 协议的扩展，引入了挑战-响应（Challenge-Response）认证机制，在保持与标准 FSD 协议兼容的同时提升了连接安全性。

## 连接流程

1. 客户端建立 TCP 连接到端口 `6809`。
2. 服务器向客户端发送 `$DI` 挑战信息。
3. 客户端使用密码和挑战码计算 HMAC 响应，回复 `$CH`。
4. 服务器验证响应，通过后发送 `$SA` 确认。
5. 连接建立完成，进入正常通信。

## 指令格式

| 指令 | 方向 | 说明 |
|------|------|------|
| `#AA` | C → S | 飞行员位置更新（含经纬度、高度等） |
| `#AP` | C → S | 飞行计划提交 |
| `#SA` | C → S | 管制员连接与席位设置 |
| `$DI` | S → C | 服务器挑战信息 |
| `$CH` | C → S | 客户端挑战响应 |
| `$SA` | S → C | 认证确认 |
| `#TM` | 双向 | 文本消息 |

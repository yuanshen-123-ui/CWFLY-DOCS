# 连飞协议

## 概述

FSD（Flight Simulator Daemon）协议是连飞网络的核心通信协议。CWFLY 同时支持标准 FSD 协议和 FSD9 扩展协议，兼容主流连飞客户端。

## 协议特点

- 基于 TCP 的文本协议，便于调试和扩展
- 客户端-服务器架构（C/S）
- 支持实时位置更新（经纬度、高度、地速）
- 支持文本聊天（私人消息与广播）
- 支持飞行计划同步

## 服务器实现

CWFLY 提供两种 FSD 服务器实现：

| 实现 | 语言 | 说明 |
|------|------|------|
| **fsd-master** | C++ | 原版 FSD 服务器，已完成安全审计和修复 |
| **fsd-py** | Python | Python 重写版本，带协议升级 v2 安全增强 |

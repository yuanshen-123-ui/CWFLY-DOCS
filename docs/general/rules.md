# 平台规则

文件编号：OPDOC-General-202601
发行日期：2026 年 7 月
参考来源：中国民航相关法规、ICAO 标准
许可协议：[CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/deed.zh)

## 第一章 总则

1. 用户注册或使用本平台即表示同意遵守本规则及其后续修订版本。
2. 平台有权根据运营需要修改规则，修改后的规则自发布之日起生效。平台将通过公告形式通知用户。
3. 如用户不同意修改后的规则，应停止使用本平台及相关服务。

## 第二章 账号规则

1. 每个用户仅限注册一个账号。CID 为平台唯一身份标识，注册后不可更改。
2. 用户名应文明、合规，不得包含侮辱性、政治敏感或侵犯他人权益的内容。
3. 用户应妥善保管账号和密码，因账号泄露造成的损失由用户自行承担。
4. 禁止转借、出租、出售或以任何形式转让账号。
5. 连续 180 天未登录的账号可能被注销。账号注销前平台会通过注册邮箱发出通知。

## 第三章 连飞规则

### 飞行员

| 要求 | 说明 |
|------|------|
| 飞行计划 | 起飞前必须提交有效的飞行计划，信息应真实准确 |
| 在线状态 | 飞行过程中保持在线连接，禁止无故断线或恶意掉线 |
| 空管指令 | 遵守空管指令，不得拒绝合法、合理的管制指令 |
| 飞行高度 | 保持正确的飞行高度层和航向，未经许可不得擅自改变 |
| 通话用语 | 使用标准陆空通话用语，保持通信简洁清晰 |

### 管制员

| 要求 | 说明 |
|------|------|
| 资质要求 | 上岗前须完成相应等级的培训和考核，持证上岗 |
| 专业态度 | 管制过程中保持专业、公正的态度，不偏袒、不滥用职权 |
| 权限使用 | 仅在分配的席位和范围内行使管制权限 |
| 交接班 | 离岗前须完成未完成的协调和移交，确保空域安全衔接 |
| ATIS | 定期更新气象信息和 NOTAM，确保信息时效性 |

## 第四章 处罚措施

| 违规行为 | 处罚 |
|---------|------|
| 语言不当、轻微刷屏 | 口头警告 |
| 未提交飞行计划连飞 | 警告 |
| 多次轻微违规 | 临时封禁 7 天 |
| 冒充管理员或工作人员 | 临时封禁 15 天 |
| 恶意干扰他人正常飞行/管制 | 临时封禁 30 天 |
| 使用作弊软件或利用系统漏洞 | 永久封禁 |
| 严重违法行为（含违法内容传播） | 永久封禁 + 报警处理 |

## 第五章 申诉

1. 被封禁用户可在处罚生效后 7 天内提出申诉。
2. 申诉应通过平台工单系统提交，需说明申诉理由并附相关证据。
3. 管理员应在收到申诉后 3 个工作日内完成审核并作出答复。
4. 申诉处理结果为平台最终决定。

# 总则

CW 模拟飞行连飞平台（CWFLY）是一个面向中文飞友的连飞平台，致力于为飞行爱好者和空中交通管制员提供稳定、专业、友好的联网飞行环境。本部分包含平台的基础规则、行为准则和账号管理规定，适用于所有平台用户。

## 平台使命

为中文飞友提供稳定、专业、友好的连飞环境，推动模拟飞行社区发展。我们相信，良好的规则是社区繁荣的基石——每一位用户的专业态度和互相尊重，共同构成了 CWFLY 的核心价值。

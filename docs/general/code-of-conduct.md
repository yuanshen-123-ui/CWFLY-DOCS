# 行为准则

## 第一章 定义

1. **飞行员（Pilot）** — 在连飞网络上使用 Swift 等客户端连接且驾驶航空器的人员。
2. **管制员（Controller）** — 在连飞网络上使用 EuroScope 等客户端连接并为航空器提供空中交通服务的人员。
3. **向下兼容（Topdown）** — 高级别管制席位覆盖低级别席位未覆盖空域的运行模式。提倡在条件允许时使用该模式以扩大管制覆盖范围。
4. **管理员（Administrator）** — 负责平台运营、用户管理和违规处理的人员。
5. **教员（Instructor）** — 负责培训新管制员和考核评估的人员。

## 第二章 总则

1. 所有平台用户应遵守中华人民共和国法律法规和本行为准则。
2. 用户之间应互相尊重，共同维护良好的连飞环境与社区氛围。
3. 禁止任何形式的歧视、辱骂、骚扰或人身攻击行为。
4. 用户在平台上的行为代表平台形象，应始终保持专业、友善的态度。
5. 所有违规行为将被记录并可能依据规则受到相应处罚。

## 第三章 飞行员行为准则

### 一般规定

1. 飞行员在连飞前应提交真实、有效的飞行计划。
2. 飞行过程中应保持专业态度，严格遵守空管指令。
3. 使用标准陆空通话用语，保持通信的简洁与准确。

### 连飞行为

1. 起飞前确认发动机、航电系统等关键设备正常工作。
2. 按照指定高度层飞行，未经管制许可不得擅自改变高度或航向。
3. 进入管制区前主动联系对应管制员，报告当前位置和高度。
4. 长航线飞行时应定期检查客户端连接状态，确保在线稳定。

### 禁止行为

1. 禁止在未提交有效飞行计划的情况下进行连飞。
2. 禁止长时间无响应（连续 5 分钟以上视为离线处理）。
3. 禁止使用非标准呼号、虚假航班号或冒用他人身份。
4. 禁止以任何形式干扰其他飞行员的正常飞行。

## 第四章 管制员行为准则

### 一般规定

1. 管制员应具备相应的资质等级，在上岗前完成必要的培训与考核。
2. 管制员应使用标准陆空通话用语，确保指令清晰无误。
3. 管制员应保持管制席位的专业性和秩序，维持良好的服务态度。

### 管制行为

1. 上岗前应获取当前气象信息和 NOTAM，全面掌握空域态势。
2. 管制过程中应保持通信清晰、简洁、专业。
3. 定期更新 ATIS 信息，确保飞行员获取最新气象与机场状态。
4. 离岗前须完成未完成的协调和移交工作，确保空管服务无缝衔接。
5. 管制过程中如遇特情，应按照标准程序冷静处置并及时上报。

### 禁止行为

1. 禁止滥用管制权限，不得发布超出权限范围的指令。
2. 禁止无故离岗或长时间无响应（超过 5 分钟视为离岗）。
3. 禁止使用非标准用语、俚语或非专业性表达。
4. 禁止基于任何理由歧视或区别对待飞行员。

## 第五章 违规处理

### 违规等级

| 等级 | 说明 | 处理方式 |
|------|------|---------|
| 轻度违规 | 语言不当、轻微影响秩序 | 口头警告 |
| 中度违规 | 多次违规、轻微作弊 | 临时封禁 7–30 天 |
| 严重违规 | 恶意破坏、严重作弊、违法行为 | 永久封禁 |

### 处理流程

1. 发现违规行为或接到用户举报
2. 管理员收集并固定违规证据（截图、日志等）
3. 评估违规严重程度并参照处罚标准作出决定
4. 通知被处罚用户，告知处罚原因与申诉途径
5. 将处理结果完整记录至审计日志

# 扇区文件

## 概述

扇区文件定义了管制区域的边界和结构，用于在线地图中实时显示管制扇区，帮助飞行员和管制员直观了解空域划分。

## 文件格式

扇区数据使用 **GeoJSON** 格式定义，每个扇区为一个多边形要素（Feature）：

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": {
        "name": "北京情报区",
        "callsign": "ZBPE_CTR",
        "type": "CTR"
      },
      "geometry": {
        "type": "Polygon",
        "coordinates": [[...]]
      }
    }
  ]
}
```

## 扇区类型

| 类型 | 说明 | 地图样式 |
|------|------|----------|
| CTR | 区域管制中心 | 蓝色填充多边形 |
| APP | 进近管制 | 蓝色填充多边形 |
| TWR | 塔台管制 | 白色点标记 |
| GND | 地面管制 | 白色点标记 |
| DEL | 放行管制 | 白色点标记 |

## 覆盖范围

平台内置 **70 个以上** FIR 扇区数据，覆盖以下区域：

- 中国大陆全部 9 个 FIR
- 东亚地区（韩国、日本等）
- 东南亚地区（越南、泰国、马来西亚、新加坡、菲律宾等）
- 北美与欧洲主要 FIR

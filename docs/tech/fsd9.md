# 直连协议

## 概述

FSD9 是 FSD 协议的扩展，在保留原有 FSD 协议兼容性的同时，引入了更安全的挑战-响应认证机制（Challenge-Response Authentication），有效防止明文密码传输带来的安全风险。

## 连接流程

FSD9 的完整连接建立流程如下：

1. 客户端建立 TCP 连接到服务器端口 `6809`。
2. 服务器向客户端发送 `$DI` 挑战信息。
3. 客户端使用密码和挑战码计算响应，回复 `$CH`。
4. 服务器验证响应，通过后发送 `$SA` 确认。
5. 连接建立完成，进入正常通信阶段。

## 认证流程示例

```
S → C: $DIserver:6809:xxxxxxxx
C → S: $CHclient:cw1234:yyyyyyyy
S → C: $SAok
```

## 心跳机制

| 参数 | 值 |
|------|------|
| 心跳间隔 | 60 秒（客户端发送） |
| 超时断连 | 120 秒无响应 |

# 连飞活动

## 活动类型

| 类型 | 说明 |
|------|------|
| 飞行活动 | 常规连飞活动，从指定起飞机场飞往到达机场 |
| 连飞活动 | 多人同时在线、相互可见的集体联网飞行 |

## 参与流程

1. 在「活动中心」浏览即将举办的活动列表。
2. 点击感兴趣的活动，查看详情后点击「报名」。
3. 活动当天在规定时间内完成「签到」。
4. 在活动时间段内连接 FSD 服务器参与连飞。

## 活动信息

每个活动页面包含以下信息：

- 活动标题与举办日期
- 起降机场及推荐航路
- NOTAM（航行通告）
- 管制席位设置与开放时间
- 飞行距离与预计飞行时长

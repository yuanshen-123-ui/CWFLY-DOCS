# 航图查询

## 查询方式

在航图查询页面输入机场 ICAO 四字码即可获取该机场的完整航图资料。

### 支持的航图类型

| 航图类型 | 英文缩写 | 说明 |
|---------|---------|------|
| 机场图 | — | 机场平面布局、停机位、滑行道信息 |
| 标准仪表离场图 | SID | 标准仪表离场程序与航路 |
| 标准仪表进场图 | STAR | 标准仪表进场程序与航路 |
| 仪表进近图 | IAP | 仪表进近程序（ILS/VOR/NDB/RNAV） |
| 停机位图 | — | 停机位详细分配信息 |

### 航图提供商

- **Jeppesen** — 完整的商业航图数据库，覆盖全球主要机场。

## 使用提示

- 输入 ICAO 代码后自动加载对应航图，支持缩放和拖动查看详情。
- 建议结合气象报文和飞行计划，提前熟悉起降机场的进离场程序。

# 权限系统

## 统一权限字段

平台统一使用 `fsdLevel` 字段作为权限控制的基础，无需额外的权限表维护。

## 权限节点

| 权限节点 | 功能说明 | 最低 FSD Level 要求 |
|---------|---------|-------------------|
| STAFF | 职员管理与公告发布 | I1（9） |
| CONTENT | 活动与内容管理 | I1（9） |
| FLIGHTPLAN | 飞行计划管理 | I1（9） |
| TICKET | 工单处理 | I1（9） |
| CONTROLLER | 管制员管理 | I2（10） |
| USER | 用户管理 | SUP（12） |
| CONFIG | 系统配置 | SUP（12） |

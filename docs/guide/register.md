# 注册与登录

## 注册账号

### 注册须知

- **CID** — 4 位数字，作为您在平台上的唯一身份标识，注册后不可更改。请选择易于记忆的数字组合。
- **用户名** — 您的显示名称，建议使用与连飞客户端一致的名称，便于其他用户识别。
- **密码** — 至少 8 位，建议包含大写字母、小写字母、数字和特殊字符的组合。
- **邮箱** — 可选填写，用于找回密码和接收平台通知。

### 注册步骤

1. 访问平台首页，点击右上角「注册」按钮。
2. 填写 CID、用户名、密码和邮箱。
3. 提交注册信息，系统将自动完成登录。

```json
// 注册请求示例
POST /api/auth/register
{
  "cid": "1234",
  "username": "MyName",
  "password": "MyP@ssw0rd",
  "email": "user@example.com"
}
```

## 登录

### 登录方式

在登录页面输入您的 CID 和密码即可登录平台。

### 常见问题

**忘记密码？**
- 在登录页面使用「找回密码」功能，通过注册邮箱重置密码。
- 如无法通过邮箱重置，可联系管理员手动处理。

**无法登录？**
- 确认 CID 和密码输入正确（注意大小写）。
- 确认账号未被封禁（FSD Level = 0 表示已封禁）。
- 尝试清除浏览器缓存后重新登录。

## 默认管理员

系统首次启动时自动创建管理员账号，请首次登录后立即修改密码以确保安全。

| 项目 | 值 |
|------|-----|
| CID | `0000` |
| 密码 | `H8j@mK2#x9Lp&5Zw` |
| 角色 | admin |
| FSD 等级 | 13 (ADM) |

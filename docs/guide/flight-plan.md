# 飞行计划

## 提交飞行计划

飞行计划是连飞活动的核心组成部分，包含航班号、机型、起降机场和航路等关键信息。起飞前必须提交有效的飞行计划。

### 必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 航班号 | 航空公司两字码 + 航班编号 | CCA1234 |
| 机型 | ICAO 标准机型代码 | B738 |
| 起飞机场 | ICAO 四字机场代码 | ZBAA |
| 到达机场 | ICAO 四字机场代码 | ZSSS |
| 飞行规则 | IFR（仪表飞行）/ VFR（目视飞行） | IFR |

### SimBrief 导入

平台支持通过 SimBrief 用户 ID 导入飞行计划，系统将自动填充航路、燃油量、备降场等详细信息，大幅简化计划提交流程。

## 飞行档案

已完成的飞行记录会自动归档，您可以在「飞行档案」页面查看历史飞行记录，包括航路、机型、起降时间等完整信息。

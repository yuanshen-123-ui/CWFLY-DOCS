# 用户管理

## 功能

- 查看所有注册用户列表。
- 编辑用户信息（用户名、角色、FSD 等级、FSD 类型）。
- 删除违规或不需要的用户账号。

## 连飞等级

| 值 | 等级 | 说明 |
|----|------|------|
| 0 | BANNED | 账号已封禁 |
| 1 | OBS | 观察员（Observer） |
| 2 | S1 | 地面/放行管制员 |
| 3 | S2 | 塔台管制员 |
| 4 | S3 | 终端/进近管制员 |
| 9 | I1 | 塔台教员（Instructor） |
| 12 | SUP | 督导（Supervisor） |
| 13 | ADM | 管理员（Administrator） |

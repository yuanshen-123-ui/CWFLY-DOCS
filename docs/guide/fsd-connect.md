# 客户端连接

## 客户端选择

| 客户端 | 平台 | 特点 |
|--------|------|------|
| Swift | Windows / Mac / Linux | 跨平台飞行员客户端，全平台兼容，推荐使用 |
| EuroScope | Windows | 专业管制员客户端，功能强大的空管工具 |

## 连接配置

1. 打开您选择的连飞客户端设置页面。
2. 填写以下连接参数：
   - **服务器地址**：您的 FSD 服务器 IP 地址或域名
   - **端口**：`6809`
   - **登录名**：您的 CID
   - **密码**：您的平台密码
3. 选择连接模式：**飞行员（Pilot）** 或 **管制员（ATC）**。
4. 保存设置并连接。

## 常见问题

**无法连接？**

- 确认 FSD 服务器正在运行。
- 检查防火墙是否允许客户端访问端口 6809。
- 确认 CID 和密码输入正确。
- 确认您的 FSD 等级未被封禁（FSD Level ≠ 0）。

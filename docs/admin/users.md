# 用户管理

## 功能概述

- 查看所有注册用户的列表。
- 编辑用户信息（用户名、角色、FSD 等级、FSD 类型）。
- 删除违规或不再需要的用户账号。

## FSD 等级说明

| 等级值 | 等级名 | 说明 |
|--------|--------|------|
| 0 | BANNED | 账号已封禁 |
| 1 | OBS | 观察员（Observer） |
| 2 | S1 | 地面/放行管制员 |
| 3 | S2 | 塔台管制员 |
| 4 | S3 | 终端/进近管制员 |
| 5–8 | T2–C3 | 程序塔台/区域管制员 |
| 9–11 | I1–I3 | 教员（Instructor） |
| 12 | SUP | 督导（Supervisor） |
| 13 | ADM | 管理员（Administrator） |

# 管理后台

## 概述

管理后台提供 CWFLY 平台的完整管理功能，基于 FSD 等级（fsdLevel）权限系统控制访问。拥有相应权限的管理员可通过后台进行用户管理、内容管理、日志审计和审批操作。

## 访问方式

- **侧边栏**：点击「管理后台」进入。
- **用户菜单**：点击个人头像，选择「管理员中心」。

## 权限等级

| 角色 | 最低 FSD Level | 等级名称 | 管理范围 |
|------|---------------|----------|---------|
| 协管员基础 | ≥ 9 | I1（塔台教员） | 公告、活动、工单管理 |
| 高级协管员 | ≥ 10 | I2（进近教员） | 管制员、日志、在线管理 |
| 管理员 | ≥ 12 | SUP（督导） | 用户管理、系统配置 |
| 超级管理员 | 13 | ADM（管理员） | 最高权限，全功能访问 |

## 管理功能一览

| 分组 | 功能 | 说明 |
|------|------|------|
| 管理 | 用户管理 | 编辑用户角色、FSD 等级、FSD 类型 |
| 管理 | 管制员管理 | 管理管制员信息和评级 |
| 管理 | 公告管理 | 发布、编辑、置顶平台公告 |
| 管理 | 权限管理 | 查看 FSD 等级权限矩阵 |
| 日志 | 登录日志 | 查看用户登录记录 |
| 日志 | 审计日志 | 查看后台操作记录 |
| 内容 | 活动管理 | 创建和编辑连飞活动 |
| 内容 | 飞行计划管理 | 管理用户提交的飞行计划 |
| 内容 | 工单管理 | 处理用户提交的工单 |
| 内容 | 职员公示管理 | 管理职员信息公示 |
| 审批 | 角色变更申请 | 审批用户角色变更 |
| 审批 | 职员申请 | 审批职员申请 |
| 审批 | 管制申请 | 审批管制员申请 |

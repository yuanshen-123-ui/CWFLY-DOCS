# 飞行情报区

## 一、什么是飞行情报区

飞行情报区（Flight Information Region，FIR）是 ICAO 定义的为航空器提供飞行情报服务和告警服务的空域范围。全球空域被划分为多个 FIR，每个 FIR 由所在国家或地区的空中交通管制部门负责管理。

## 三、中国香港与台湾

- **香港飞行情报区（VHHK FIR）** — 覆盖香港及周边空域
- **台北飞行情报区（RCAA FIR）** — 覆盖台湾及周边空域

## 五、飞行注意事项

1. 进入新的 FIR 前，须通过当前管制员联系下一 FIR 的管制单位。
2. 跨 FIR 飞行时，注意高度层配备的差异。
3. 不同 FIR 可能有不同的频率和通信要求。
4. 在 FIR 边界区域注意保持正确的航向和高度。

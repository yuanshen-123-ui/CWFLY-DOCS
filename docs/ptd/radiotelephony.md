# 陆空通话

## 基本用语表

| 中文 | 英文 | 含义 |
|------|------|------|
| 请求开车 | Request startup | 请求启动发动机 |
| 请求推出 | Request pushback | 请求推出停机位 |
| 请求滑行 | Request taxi | 请求滑行至指定位置 |
| 请求起飞 | Request takeoff / Line up and wait | 请求进入跑道并起飞 |
| 请求进近 | Request approach | 请求进近管制服务 |
| 复飞 | Go around | 中止进近，执行复飞程序 |

## 通话示例

### 请求开车

```
飞行员：北京地面，晚上好，CES1234，停机位A201，请求开车
管制员：CES1234，北京地面晚上好，可以开车，修正海压1013
飞行员：可以开车，修正海压1013，CES1234
```

### 请求滑行

```
飞行员：北京地面，CES1234请求滑行，目的地上海
管制员：CES1234，滑行至36L等待点，沿A-B-C滑行道
飞行员：沿A-B-C滑行道至36L等待点，CES1234
```

### 请求起飞

```
飞行员：北京塔台，CES1234，36L等待点，请求起飞
管制员：CES1234，36L可以起飞，风350度4米秒，修正海压1013
飞行员：可以起飞，CES1234
```

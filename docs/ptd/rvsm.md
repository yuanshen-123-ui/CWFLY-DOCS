# 飞行高度层

## 一、什么是 RVSM

RVSM（Reduced Vertical Separation Minimum，缩小垂直间隔标准）是一种将 FL290 至 FL410（即 29,000 至 41,000 英尺，约 8,900 至 12,500 米）之间的垂直间隔从原来的 2,000 英尺缩小至 1,000 英尺的运行标准。

## 二、RVSM 空域范围

| 参数 | 值 |
|------|------|
| RVSM 空域 | FL290 – FL410（含） |
| 垂直间隔 | 1,000 英尺 |
| 非 RVSM 空域（FL290 以下） | 2,000 英尺间隔（IFR） |

## 三、高度层配备规则

### IFR 飞行

| 航向 | 高度层（英尺） |
|------|--------------|
| 000°–179°（向东） | FL290, FL310, FL330, FL350, FL370, FL390, FL410 |
| 180°–359°（向西） | FL300, FL320, FL340, FL360, FL380, FL400 |

### 半高度层（RVSM 空域内）

部分航路使用半高度层（如 FL295、FL305）以增加容量，具体需参照航路图或空管指令。

## 四、运行要求

1. 进入 RVSM 空域的航空器须具备 RVSM 适航能力。
2. 飞行员须保持指定的高度层，未经许可不得擅自改变。
3. 高度偏离超过 200 英尺时应立即报告管制员。
4. 如遇 Turbulence（颠簸）导致无法保持 RVSM 高度，应申请非 RVSM 高度层。

## 五、转换高度

- **TA（Transition Altitude，过渡高度）** — 起飞后从标准海压（QNH）转换为标准气压（1013 hPa）的高度。
- **TL（Transition Level，过渡高度层）** — 进近时从标准气压转换回标准海压的高度层。
- **TH（Transition Height，过渡高）** — 以机场标高为基准的过渡高度。

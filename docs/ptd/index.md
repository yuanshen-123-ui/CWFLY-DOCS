# 飞行员指南

## 概述

飞行员培训部门（Pilot Training Department，PTD）为 CWFLY 平台的飞行员提供连飞所需的知识和技能指导。无论您是首次进行联网飞行的新手，还是希望提升飞行技能的资深飞友，这里都能找到实用的参考资料。

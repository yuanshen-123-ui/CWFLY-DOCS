# 常见问题

## 如何连接 FSD 服务器？

安装 Swift 等连飞客户端，在设置中配置 FSD 服务器地址和您的 CID 即可连接。详细步骤请参阅 [FSD 客户端连接](/guide/fsd-connect) 章节。

## 为什么我看不到其他飞机？

- 确认已正确连接到 FSD 服务器并且状态为在线。
- 确认客户端版本为最新，与服务器兼容。
- 检查防火墙设置是否阻止了客户端访问端口 6809。

## 飞行计划提交后多久生效？

飞行计划提交后立即生效，将自动同步至 FSD 服务器，无需等待审核。

## 如何成为管制员？

1. 完成管制员基础培训课程。
2. 通过理论考试（70 分合格）。
3. 提交管制员申请并通过面试。
4. 通过实操考核后正式上岗。

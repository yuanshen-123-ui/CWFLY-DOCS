# Swift 连飞教程

## 一、Swift 简介

Swift 是一款跨平台的连飞客户端，支持 Windows、macOS 和 Linux 操作系统。它集成了连飞连接、飞行控制和地图显示功能，是 CWFLY 平台推荐的连飞客户端之一。

## 二、下载与安装

1. 访问 [Swift 官方网站](https://swift-project.org/) 下载对应操作系统的最新版本。
2. 按照安装向导完成安装。
3. 启动 Swift，首次运行需进行基础配置。

## 三、连接配置

### 3.1 设置服务器

1. 打开 Swift，点击顶部菜单的「Settings」进入设置界面。
2. 在「Network」选项卡中，点击「Add」添加新的服务器配置。
3. 填写以下信息：
   - **Address**：您的 FSD 服务器 IP 地址或域名
   - **Port**：`6809`
   - **Login**：您的 CID
   - **Password**：您的平台密码

### 3.2 选择角色

在连接前，选择您要使用的角色：
- **Pilot（飞行员）** — 驾驶航空器参与连飞
- **ATC（管制员）** — 提供空中交通管制服务

## 四、基本操作

### 飞行员模式

1. 连接成功后，在 Aircraft 面板中选择您的机型。
2. 提交飞行计划（Flight Plan），填写航班号、起降机场、航路等信息。
3. 进入驾驶舱后，Swift 将自动发送位置更新至服务器。

### 管制员模式

1. 选择管制员模式并连接。
2. 在 ATC 面板中选择您要占用的席位（如 ZBAA_TWR）。
3. 设置您的管制范围并开始提供服务。

## 五、常见问题

- **无法连接服务器** — 确认服务器地址和端口正确，检查防火墙设置。
- **看不到其他飞机** — 确认已正确连接且状态为在线，尝试刷新地图。
- **音频通信异常** — 检查音频设备设置和 VoIP 配置。

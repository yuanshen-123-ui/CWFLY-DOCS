# 连飞准备

## 准备工作清单

1. **注册账号** — 在 CWFLY 平台注册您的 CID。
2. **安装客户端** — 安装 FSD 兼容的连飞客户端（推荐 Swift）。
3. **配置连接** — 在客户端中配置服务器地址和您的 CID。
4. **提交飞行计划** — 在平台提交有效的飞行计划。
5. **检查航图** — 查询起降机场的航图，熟悉进离场程序。
6. **查询气象** — 获取起降机场及备降场的 METAR/TAF 报文。

## 推荐客户端

| 客户端 | 平台 | 特点 |
|--------|------|------|
| Swift | Windows / Mac / Linux | 跨平台客户端，全平台兼容，推荐飞行员使用 |
| EuroScope | Windows | 专业管制员客户端，功能强大的空管工具 |

## 连接参数

- **服务器地址**：`localhost`（本地开发）或 FSD 服务器 IP 地址
- **端口**：`6809`（FSD9 协议）
- **登录名**：您的 CID
- **密码**：您的平台密码
